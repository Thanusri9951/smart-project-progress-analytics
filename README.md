# Smart Project Progress Analytics and Prediction System

A Streamlit application for project monitoring, data mining, risk review, anomaly detection, forecasting, team analytics and report generation.

## Run locally on Windows
```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

If Windows Application Control blocks `pip.exe`, use `python -m pip` as shown. If it blocks Python-launched pip too, ask the device administrator to approve the package installer; do not disable security controls.

## Dataset
Upload a CSV with these required fields:
`project_id, task_id, task_name, team_member, start_date, deadline, actual_completion_date, estimated_hours, actual_hours, completion_pct, status`

Optional: `project_name`. Dates should be YYYY-MM-DD. Use one row per task and unique task IDs. `actual_completion_date` can be blank for unfinished tasks.

Download a CSV template from the sidebar. The built-in dataset has 150 synthetic tasks across 10 projects.

## Included features
1. Overview dashboard and project filters.
2. Task/project explorer and project notes.
3. K-Means performance clustering.
4. Decision Tree and Random Forest risk-label demonstration with holdout metrics.
5. Isolation Forest anomaly flags.
6. Progress-rate remaining-duration estimates.
7. Team workload and progress analytics.
8. Rule-based recommendations.
9. Project comparison.
10. TXT, PDF and Excel report exports.
11. Demo admin login and upload history stored in SQLite.

## Important model limitations
- Risk categories are generated by transparent overdue/progress rules. Decision Tree and Random Forest metrics measure how well the models reproduce those rule labels. They do not establish real-world future-risk accuracy.
- Isolation Forest identifies unusual feature combinations. An anomaly is a review signal, not proof of a problem.
- Remaining duration assumes the observed progress rate continues. It is not a trained time-series forecast.
- Association patterns are simple frequency summaries, not causal rules.
- For defensible prediction, collect dated progress snapshots and actual final outcomes from many completed projects, then train/test using a project- or time-based split and compare predictions with unseen actual outcomes.

## Deployment to Streamlit Community Cloud
1. Push the project files to a GitHub repository.
2. Open https://share.streamlit.io/ and connect GitHub.
3. Choose repository, branch and `app.py`.
4. Deploy; dependencies install from `requirements.txt`.

SQLite files on ephemeral cloud hosting may not persist across restarts or replicas. For persistent multi-user deployment, move users, notes and logs to a managed database such as PostgreSQL. Protect the app with proper secrets and authentication before public access.
