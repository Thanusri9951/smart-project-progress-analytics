# Abstract

The Smart Project Progress Analytics and Prediction System is an integrated data-driven application designed to monitor project execution, analyse task and team performance, identify unusual activities, and support project decision-making. Basic spreadsheet reporting can summarize task completion and generate charts, but managers still need to interpret patterns, assess risks, compare teams and estimate future progress manually.

The proposed system accepts project task data containing project identifiers, task names, assigned members, planned start dates, deadlines, actual completion dates, estimated and actual effort, completion percentages and status. The application validates and preprocesses the uploaded records before producing project summaries and interactive visualizations. K-Means clustering groups tasks by progress and effort characteristics. Decision Tree and Random Forest models demonstrate interpretable risk classification against transparent rule-generated labels. Isolation Forest identifies unusual combinations of task progress, effort and delay indicators. A progress-rate estimator calculates indicative remaining durations, while team analytics and project comparisons help reveal workload and performance differences. A recommendation module converts detected risk and performance patterns into review actions. Reports can be exported as PDF, Excel and text files.

The system is implemented using Python, Streamlit, pandas, scikit-learn, Plotly, SQLite and ReportLab. Its contribution is the integration of repeatable data preparation, descriptive analytics, exploratory data mining, risk review, anomaly flagging, task-duration estimation and reporting in one application. The prototype is intended for academic demonstration. Its outputs must be validated against real historical project outcomes before being treated as reliable predictions or used for critical decisions.
